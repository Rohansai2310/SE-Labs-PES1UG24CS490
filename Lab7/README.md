# Lab 07 — Fuzz Testing

This lab applies property-based fuzz testing with Hypothesis to identify and
fix input-validation bugs in a Python car-rental processor.

## Focus

- Generate unexpected text and `None` inputs with Hypothesis.
- Detect parsing and validation failures in three processor functions.
- Harden the application so malformed input is handled safely.

## Completed work

The completed Lab 7 source code, fuzz tests, and submission report are in the
[Lab 7 folder of the Car Rental Rate repository](https://github.com/Rohansai2310/L6_L7_02_car_rental_rate/tree/main/Lab%207).
